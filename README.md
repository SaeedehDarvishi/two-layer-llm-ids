# two-layer-llm-ids
Code and prompts for A Two-Layer Framework for Explainable Intrusion Detection and Threat Analysis Using Large Language Models

Due to the large size of the original CICIDS2018 dataset files, the raw files are not included in this repository. The preprocessing code used to generate the final dataset is provided for reproducibility. The final preprocessed dataset used in the experiments is available through the following link:
**[Download the final CICIDS2018 dataset](https://drive.google.com/drive/folders/1OBhFB8sMJh523OQVwEFLdQTB1ZnS1H11?usp=drive_link)**

The IDS Full Code is Accessible in the paper entitled "[**Tree-Based Intelligent Intrusion Detection System in Internet of Vehicles**](https://arxiv.org/pdf/1910.08635.pdf)" published in IEEE GlobeCom 2019.
